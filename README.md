# Made to Scale: website

Static site (HTML, CSS, vanilla JS) for https://madetoscale.site, hosted free on GitHub Pages.

- `index.html`: homepage
- `services/`, `pricing/`: sub-pages
- `css/`, `js/`, `assets/`: styles, script, images and hero video
- `CNAME`: custom domain for GitHub Pages
- `sitemap.xml`, `robots.txt`: search engine files
